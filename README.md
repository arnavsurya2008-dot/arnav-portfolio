## 🌐 Deploying to the Web (Free Hosting)

### Option 1: Netlify (Fastest — 10 Seconds, Instant Live URL)
1. Open **[app.netlify.com/drop](https://app.netlify.com/drop)** in your browser.
2. Drag and drop the folder `my portfolio 2` directly onto the page.
3. Your site goes live instantly!
4. Click **Site Configuration** > **Change Site Name** and set it to:
   ```text
   arnav-portfolio
   ```
   Your live URL will be: **`https://arnav-portfolio.netlify.app`**

---

### Option 2: GitHub Pages (Permanent & Connects to Your Profile)
1. Go to [github.com/new](https://github.com/new) and create a public repository named:
   ```text
   arnav-portfolio
   ```
2. Open PowerShell in this folder and run:
   ```powershell
   git remote add origin https://github.com/<YOUR-GITHUB-USERNAME>/arnav-portfolio.git
   git push -u origin main
   ```
3. In your GitHub repository:
   - Click **Settings** > **Pages** (in the left sidebar).
   - Under **Build and deployment > Branch**, select `main` and `/ (root)`, then click **Save**.
4. In about 60 seconds, your portfolio will be live at:
   **`https://<YOUR-GITHUB-USERNAME>.github.io/arnav-portfolio/`**

---

### Option 3: Vercel
1. Go to [vercel.com/new](https://vercel.com/new).
2. Import your `arnav-portfolio` GitHub repository.
3. Click **Deploy**.
4. Your live URL will be: **`https://arnav-portfolio.vercel.app`**
